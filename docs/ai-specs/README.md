# AI Specs — PORTIO

Especificações executáveis para IAs que geram ou editam código neste repositório.
Leia o arquivo relevante **antes** de tocar no código. São curtos por design — cada token conta.

## Índice

| Arquivo | Quando ler |
|---------|-----------|
| [design-tokens.md](design-tokens.md) | Qualquer mudança em CSS, Tailwind, cores, tipografia, espaçamento |
| [components.md](components.md) | Criar ou editar componentes React / shadcn/ui |
| [screens.md](screens.md) | Implementar ou alterar telas específicas |
| [backend.md](backend.md) | Qualquer mudança no .NET API |
| [guard-rails.md](guard-rails.md) | **Sempre** — lista do que NÃO fazer |

## Como usar

1. Leia `guard-rails.md` primeiro — sempre.
2. Leia o spec relevante à tarefa.
3. Na dúvida, consulte `docs/design-handoff/reference/index.html` como source of truth visual.
4. Siga `CLAUDE.md` na raiz para convenções de código gerais.

## Princípio

PORTIO é uma **ferramenta**, não um coach. Sóbrio, preciso, mínimo. Sem gamificação, sem streaks, sem nudges motivacionais.
